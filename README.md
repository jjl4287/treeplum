# Tree Plum · Fluidity

A modern art web experience exploring organic chaos through trees, plum blossoms, and fluid motion. Optimized for mobile Safari.

## 🌸 Experience

This is a purely visual scrolling experience — no information, just art. The journey unfolds across approximately 13 screens worth of organic chaos:

### Phases
1. **Awakening** — Darkness gives way to the first whispers of life
2. **Roots** — Earth tones emerge, grounding the experience
3. **Growth** — Deep greens and the energy of rising branches
4. **Bloom** — Plum blossoms explode across the canvas
5. **Peak Chaos** — Maximum fluidity, petals, and organic motion
6. **Fruit** — Rich plum colors, the harvest of the journey
7. **Descent** — A gentle falling, petals drifting down
8. **Return** — Back to darkness, the cycle complete

## ✨ Features

### Visual Elements
- **Perlin noise fluid simulation** — Organic, ever-changing flow fields
- **Multi-layer particle system** — Falling petals, leaves, and plum fruits
- **SVG artwork** — Hand-crafted trees, blossoms, branches, and vines
- **Organic blob morphing** — Soft, breathing background shapes
- **Zen circles (Enso)** — Meditative circular elements
- **Water stream effects** — Flowing droplets and streams
- **Parallax layering** — Depth through motion

### Interactivity
- **Touch ripples** — Tap anywhere to create expanding ripple effects
- **Finger trails** — Drag to leave glowing particle trails
- **Chaos bursts** — Touch during peak chaos creates particle explosions
- **Gyroscope response** — Tilt your device to shift the fluid and particles

### Audio
- **Ambient soundscape** — Wind, water, and deep drones
- **Chime triggers** — Touch interactions play gentle bell tones
- **Scroll-reactive mixing** — Audio layers shift with your journey

## 🍎 Technical Details

### Mobile Safari Optimizations
- Viewport meta tags for fullscreen experience
- Touch event handling with passive listeners
- GPU-accelerated canvas rendering
- Reduced motion support for accessibility
- Safe area inset handling

### Technologies Used
- Vanilla JavaScript (no frameworks)
- HTML5 Canvas for particle/fluid rendering
- SVG for scalable artwork
- Web Audio API for generative soundscape
- CSS animations and transforms
- Device Orientation API for gyroscope

## 🚀 Usage

Simply open `index.html` in a mobile Safari browser (or any modern browser).

1. Touch the blossom to begin
2. Scroll slowly to experience the journey
3. Touch and drag to interact with the fluid
4. Tilt your device to influence the motion

## 📱 Recommended Viewing

- **Device**: iPhone or iPad
- **Browser**: Safari
- **Orientation**: Portrait
- **Audio**: Headphones recommended
- **Setting**: A quiet, contemplative space
